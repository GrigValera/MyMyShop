# Каталог интеграций и ответственность

Сейчас приложение не интегрировано с внутренними бизнес-системами. **CURRENT:** сетевой доступ к DummyJSON — публичный demo-режим каталога, а не сервер магазина. При `?source=api` браузер обращается к DummyJSON напрямую; это допустимо только для публичного, нечувствительного demo-источника. Будущие операции магазина проходят по цепочке `веб-приложение → MyMyShop Backend/Application API → доменная/прикладная граница → адаптер интеграции → внешняя система`.

| Бизнес-возможность | Целевой внутренний владелец | Внешняя категория | Направление и типичный механизм (PROPOSED) | Данные | Вопрос безопасности | Статус / поставщик |
| --- | --- | --- | --- | --- | --- | --- |
| Demo-каталог | UI каталога | Публичный API DummyJSON | Чтение браузером через RTK Query | Публичные поля товара | Нет credentials магазина | CURRENT / DummyJSON |
| Содержимое товаров | Каталог | PIM/CMS | Серверный импорт/запрос | Товар, категория, изображения, возможно цены/наличие | Проверка источника и прав на публикацию | OPTIONAL / не выбран |
| Настоящий вход | Идентификация/сессия | Поставщик идентификации | Серверная проверка или сценарий поставщика | Идентичность и утверждения сессии | Решения о доступе на сервере; транспорт открыт | PLANNED / не выбран |
| Обращения и жалобы | Поддержка | CRM/helpdesk | Серверный обмен обращениями/сообщениями | Переписка, при необходимости контекст заказа/Customer | Минимизация персональных данных; серверные credentials | PLANNED возможность; поставщик OPTIONAL / не выбран |
| Оплата и возврат | Платежи/возвраты | PSP/эквайер | Серверный запрос и подтверждённый callback | Оплата, связь с Order, статус возврата | При необходимости защищённый UI поставщика; проверка webhook | PLANNED / не выбран |
| Сборка заказа | Исполнение | OMS/WMS | Серверный обмен заданиями/статусами | Исполнение, остатки, отгрузка | Ограничение доступа к данным сотрудников/Customer | OPTIONAL / не выбран |
| Доставка и отслеживание | Исполнение | Перевозчик | Серверное оформление/получение статуса | Отгрузка, трек, адрес | Серверные credentials; защита адреса | PLANNED возможность; поставщик OPTIONAL / не выбран |
| Финансовая сверка | Платежи/финансы | Бухгалтерская система/ERP | Серверный экспорт/запрос | Оплаченные заказы, списания, возвраты, идентификаторы | Аудит и минимум данных | OPTIONAL / не выбран |
| Уведомления | Уведомления | Поставщик email/SMS/push | Серверная доставка и учёт статуса | Сообщение о заказе/аккаунте, настройки | Согласие и правила восстановления доступа | OPTIONAL / не выбран |
| Бизнес-показатели | Аналитика/наблюдаемость | Инструмент аналитики | Согласованный поток событий/отчётов | События товаров и заказов | Приватность, сроки хранения, отсутствие секретов | OPTIONAL / не выбран |
| Публикация отзывов | Отзывы | Сервис модерации | Серверный обмен решением | Отзыв, оценка, решение | Проверка злоупотреблений и персональных данных | OPTIONAL / не выбран |

**PROPOSED — контракт интеграции:** адаптер преобразует данные и ошибки поставщика в доменные понятия, хранит credentials на сервере, проверяет callbacks и возвращает состояния, из которых можно восстановиться. Выбор поставщика, повторные запросы и идемпотентность, сроки хранения и сверка определяются позднее. Здесь не утверждаются endpoint, транспорт событий, vendor, SLA или сертификат.

## Особенности платежей и поддержки

**PLANNED — платёж:** веб-приложение выбирает метод и может показывать защищённый компонент/перенаправление поставщика. Backend MyMyShop создаёт намерение платежа, проверяет достоверные callbacks/webhooks, связывает Payment с Order и возвращает безопасный статус. Работа с данными карты определяется моделью выбранного поставщика; MyMyShop не должен собирать сырые данные карты без отдельной утверждённой модели. Credentials backend API PSP не передаются в браузер.

**PLANNED — поддержка:** веб-приложение отправляет действия в Support API MyMyShop. Домен Support владеет перепиской и контекстом заказа; необязательный адаптер CRM/helpdesk обменивается обращениями и ответами. Credentials CRM не передаются в браузер. Нынешние ChatBot и контактная форма — локальный demo UI, а не такая интеграция.
