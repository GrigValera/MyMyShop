# ADR-0003 — Версионированное локальное хранение корзины

Статус: Accepted.

## Контекст

SHOP-05 требовал сохранять demo-корзину после обновления страницы без серверной синхронизации и утечки постороннего состояния.

## Решение

`cartPersistence` хранит только разрешённые поля строки корзины под ключом `mymyshop.cart.v1` с версией схемы 1, проверяет данные при чтении и записи, отбрасывает повреждённое содержимое и допускает недоступность хранилища. Текущим состоянием корзины UI владеет Redux.

## Последствия

При доступном хранилище корзина переживает обновление страницы в том же браузере; синхронизации вкладок/аккаунтов и проверки наличия/текущей цены нет. Настоящее оформление должно перепроверять данные на сервере. Правило согласования с серверной корзиной открыто.

## Рассмотренные альтернативы

Сохранение всего состояния Redux или данных сессии отвергнуто. Серверной корзины в текущем статическом demo нет.
