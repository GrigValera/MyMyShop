# ADR-0001 — Статический demo и серверная граница

Статус: Accepted для статического demo; архитектура с backend — PLANNED.

## Контекст

Сейчас MyMyShop — браузерная SPA с локальными/demo-данными. ROADMAP требует готовить frontend к подключению backend, сохраняя публичный demo безопасным и самостоятельным.

## Решение

Явно показывать demo-поведение. Будущие реальные бизнес-операции проходят через MyMyShop Backend/Application API; внешними интеграциями владеет сервер. Это решение о границе, а не утверждение о существующем backend или окончательной схеме API.

## Последствия

Demo не может заявлять о настоящем заказе, платеже или защите данных Customer. Контракты и адаптеры будущих функций реализуются и проверяются отдельно. Статический хостинг сам по себе не обеспечивает достоверность бизнес-операций.

## Рассмотренные альтернативы

Прямой доступ браузера к внутренним системам раскрывал бы credentials и связывал UI с поставщиками; для целевой системы он отвергнут. Создание backend не входит в этот документационный ticket.
