# ADR-0004 — Детерминированный снимок каталога и дополнительный режим API

Статус: Accepted.

## Контекст

SHOP-03 требовал стабильной полной фильтрации demo-каталога с сохранением упражнения с публичным API из SHOP-02.

## Решение

Основной каталог использует датированный локальный снимок товаров DummyJSON. Параметр `?source=api` включает живой DummyJSON через RTK Query. Ссылки на товары сохраняют выбранный источник. Изображения остаются на внешних URL; при ошибке показывается локальная заглушка.

## Последствия

Данные и число результатов основного каталога детерминированы, но изображения могут требовать сеть. API-режим может меняться, а его локальные фильтры и счётчики охватывают только загруженные страницы. Будущие Catalog API и преобразование DTO — отдельная работа.

## Рассмотренные альтернативы

Только живой API лишил бы demo стабильных результатов. Копирование внешних изображений не выбрано из-за неподтверждённых прав на распространение.
