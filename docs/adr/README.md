# Архитектурные решения (ADR)

Статус `Accepted` относится только к решениям, уже подтверждённым репозиторием и roadmap. Он не утверждает будущие backend, поставщика или способ эксплуатации. Статус `Proposed` потребовал бы отдельного согласования перед реализацией.

| ADR | Статус | Основание |
| --- | --- | --- |
| [0001 Статический demo и серверная граница](0001-static-demo-and-backend-boundary.md) | Accepted для статического demo; целевая граница PLANNED | ROADMAP и текущая SPA |
| [0002 Безопасная demo-сессия](0002-safe-demo-session-boundary.md) | Accepted | Направление SHOP-01/08; сервис сессии |
| [0003 Локальное хранение корзины](0003-cart-local-persistence-boundary.md) | Accepted | SHOP-05; адаптер хранения |
| [0004 Снимок каталога и режим API](0004-catalog-local-snapshot-and-api-mode.md) | Accepted | SHOP-03; источники каталога |

Открыты: устройство backend, схема API, транспорт сессии, поставщики, способ оплаты, жизненный цикл заказа и согласование корзины. Ни один ADR не утверждает микросервисы, облачную платформу или поставщика интеграции.
