# ADR-0002 — Demo-сессия только в памяти за сервисной границей

Статус: Accepted.

## Контекст

SHOP-01 удалил старые mock-credentials; SHOP-08 позднее развивает типизированную архитектуру авторизации. Публичный demo не должен создавать впечатление защищённого доступа.

## Решение

`sessionService` использует `demoSessionAdapter`, возвращает идентичность для отображения, удаляет известные старые ключи credentials и не сохраняет сессию. Фиксированный DemoUser не даёт прав доступа.

## Последствия

Обновление страницы завершает demo-сессию. Для настоящей авторизации нужны новый адаптер, обработка истечения/ошибок и серверная проверка. Текущая Profile — только demo-страница.

## Рассмотренные альтернативы

Хранение mock-пароля/токена в браузере и имитация защищённых маршрутов отвергнуты как небезопасные и вводящие в заблуждение. Поставщик реальной авторизации не выбран.
