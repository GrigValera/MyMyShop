# Концептуальная карта доменов и ответственности

Значение статусов дано в [обзоре](ARCHITECTURE.md). Ниже определяются обязанности, а не окончательные поля, схема хранения, маршруты API или развёрнутые модули. `Account` — область интерфейса; `Customer` — бизнес-сущность; `Customer Profile` — персональные данные; `Session` — текущее состояние идентификации.

## CURRENT — понятия в коде

| Понятие | Подтверждение в репозитории | Ограничение |
| --- | --- | --- |
| Product | Локальный снимок и дополнительный ответ DummyJSON; карточки/PDP | Форма источника во многом доходит до UI; общего доменного преобразования нет |
| Category | Метаданные снимка и категории DummyJSON | Семантика полного локального набора и загруженных API-страниц различается |
| Cart / CartItem | Redux slice и версионированное локальное хранение | Снимок для отображения, а не заказ или достоверный итог |
| Session / DemoUser | `sessionService`, адаптер и auth slice | Только память, без прав доступа и Customer-идентичности |
| Account overview | `accountService → demoAccountAdapter`; статический display-only fixture | Не Customer Profile, не запись покупателя и не источник авторизации |
| Данные Review / Rating | Рейтинг товара есть в снимке и карточках; поле `reviews` запрашивается в API-режиме PDP, но отсутствует в локальном снимке | Базовый компонент `Reviews` не образует полноценный UI; нет домена и отправки отзывов |

## PLANNED — будущие понятия

Вероятный владелец означает **предложение по ответственности**, а не существующий backend-модуль. Связи концептуальны и уточняются в implementation tickets.

| Понятие | Назначение и связь | Вероятный владелец | Статус |
| --- | --- | --- | --- |
| Customer | Покупатель магазина, связанный с аккаунтом и заказами | Покупатель | PLANNED |
| CustomerProfile | Изменяемые контактные и отображаемые данные Customer | Покупатель | PLANNED |
| Address | Адрес Customer для оформления и доставки | Покупатель | PLANNED |
| Order | Оформленная покупка с жизненным циклом; связана с оплатой и исполнением | Заказы | PLANNED |
| OrderItem | Коммерческий снимок товара, количества и согласованных условий внутри Order | Заказы | PLANNED |
| OrderStatus | Бизнес-состояние Order; точный набор не утверждён | Заказы | PLANNED |
| Payment | Попытка/результат оплаты, связанный с Order | Платежи | PLANNED |
| PaymentStatus | Статус, подтверждённый платёжным поставщиком; набор не утверждён | Платежи | PLANNED |
| Refund | Возврат средств по допустимому Order/Payment | Платежи/возвраты | PLANNED |
| Shipment | Единица исполнения, связанная с Order | Исполнение | PLANNED |
| ShipmentStatus | Состояние по данным исполнения/перевозчика | Исполнение | PLANNED |
| Review | Отзыв Customer о товаре | Отзывы | PLANNED |
| Rating | Оценка в отзыве/у товара; агрегация не определена | Отзывы | PLANNED |
| SupportConversation | Обращение с возможной связью с Order | Поддержка | PLANNED |
| SupportMessage | Сообщение внутри SupportConversation | Поддержка | PLANNED |
| NotificationPreference | Выбор Customer для допустимых уведомлений | Уведомления/покупатель | PLANNED |
| RecentlyViewedItem | История просмотра товаров; первый вариант может быть локальным | Каталог/опыт покупателя | PLANNED |

**PROPOSED — инвариант:** OrderItem сохраняет коммерческий снимок, чтобы история заказа не менялась при последующем изменении Product или цены. Реальное оформление должно заново проверить на backend клиентские цены, итоги, наличие и права. В нынешней корзине эти правила не реализованы.

## Матрица владения доменами

| Домен | Основная обязанность | Экран frontend | Планируемая серверная ответственность | Внешняя зависимость | Статус |
| --- | --- | --- | --- | --- | --- |
| Идентификация/сессия | Состояние доступа | Вход и сессия | Граница идентификации | Поставщик необязателен | CURRENT demo; backend PLANNED |
| Покупатель/аккаунт | Профиль, адрес, настройки | Demo Account Overview сейчас; остальные разделы позднее | Граница Customer | Передача в CRM необязательна | CURRENT demo overview / PLANNED |
| Каталог | Поиск товаров и содержимое | Каталог/PDP | Граница Catalog | PIM необязателен | CURRENT frontend; backend PLANNED |
| Корзина | Намерение купить | Cart/Drawer | Граница Cart | Не требуется | CURRENT локально; backend PLANNED |
| Оформление | Проверка и создание покупки | Checkout | Граница Checkout | Адаптеры доставки/оплаты по необходимости | PLANNED |
| Заказы | Оформленная покупка и история | Account/Orders/Details | Граница Orders | OMS/ERP необязательны | PLANNED |
| Платежи/возвраты | Денежные состояния | Checkout/Order Details | Граница Payments | PSP нужен для реальной оплаты | PLANNED |
| Исполнение/отгрузки | Ход доставки | Order Details/Tracking | Граница Fulfillment | WMS/перевозчик необязательны | PLANNED |
| Отзывы/оценки | Обратная связь | PDP/Account | Граница Reviews | Модерация необязательна | SOURCE DATA CURRENT / FEATURE PLANNED |
| Поддержка | Общение с покупателем | Чат/контакты | Граница Support | CRM/helpdesk необязателен | CURRENT локальный UI; интеграция PLANNED |
| Уведомления | Сообщения о статусах | Account/уведомления | Граница Notifications | Поставщик необязателен | PLANNED |

## Источники истины

| Данные | CURRENT источник | Будущий источник истины | Статус |
| --- | --- | --- | --- |
| Сессия | Память Redux и demo-адаптер | Серверная сессия | CURRENT / PLANNED |
| Обзор аккаунта | Статический demo fixture за `accountService`, без сохранения | Серверная граница Customer | CURRENT demo / PLANNED |
| Корзина | Redux и `localStorage` | Серверная корзина авторизованного Customer; правило согласования открыто | CURRENT / PLANNED |
| Каталог | Снимок и дополнительный режим DummyJSON | Серверная граница Catalog; PIM необязателен | CURRENT / PLANNED |
| Заказ | Нет | Серверный домен Orders | PLANNED |
| Платёж | Нет | Серверный домен Payments и подтверждённые события PSP | PLANNED |
| Отгрузка | Нет | Серверный домен Fulfillment и при необходимости обновления перевозчика | PLANNED |
| Отзывы | В локальном снимке `reviews` отсутствует; API-запрос PDP запрашивает поле, базовый компонент вывода есть | Серверный домен Reviews и полноценное представление | SOURCE DATA CURRENT / FEATURE PLANNED |
| Поддержка | Локальный ChatBot в памяти; форма пишет в console | Серверный домен Support | CURRENT demo / PLANNED |

Концептуальные события `OrderPlaced`, `PaymentAuthorized`, `ShipmentStatusChanged`, `ReturnRequested` и `SupportConversationCreated` могут помочь описать будущие процессы (**PROPOSED**). Они не требуют шины событий: в модульном монолите возможны внутренние вызовы. Транспорт и гарантии доставки событий не выбраны.
